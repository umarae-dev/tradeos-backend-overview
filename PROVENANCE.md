# Provenance

This public repository is not a synthetic demo created from scratch for presentation purposes. It is a sanitized, independently runnable reference edition derived from architectural patterns and selected safe modules developed in the private Zynost production backend.

## Verified private-repository development lineage

The private `umarae-dev/tradeos-backend` repository was imported to GitHub on 8 August 2026 and then continued through iterative commits covering production intelligence work including:

- owner-scoped intelligence platform;
- deterministic evidence construction;
- consensus and FlowState intelligence;
- stored-result rehydration;
- directional evidence consensus;
- multilingual Decision Brief and Explain flows;
- Decision Brief reliability improvements.

The public repository intentionally does not rewrite Git history or backdate public commits. Public-source extraction began later and is recorded using its real commit dates.

## What was copied or adapted

Safe/keyless modules, data contracts, deterministic design patterns and tests are copied or adapted where they do not expose production credentials, user data, private provider configuration, proprietary prompts or commercial tuning.

## What is newly implemented for the public edition

Where production code depends on private systems, this repository supplies an independently runnable reference implementation with explicit public defaults. These defaults are identified in code and are not represented as the exact commercial production tuning.

## Why this matters

Reviewers can distinguish three things clearly:

1. existing production development;
2. public extraction/adaptation;
3. public-only reference code added for reproducibility.

No commit history has been fabricated to make the project appear older than it is.
