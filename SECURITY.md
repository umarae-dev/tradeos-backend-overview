# Security Policy

Zynost Intelligence is a production research platform. This public repository documents architecture and methodology; it is not the production backend.

## Do not publish or request

Please do not submit, commit, or request disclosure of:

- API keys or provider credentials;
- database credentials or connection strings;
- authentication secrets;
- private user data;
- production environment files;
- internal prompts or proprietary scoring/tuning intended to remain private;
- operational runbooks, infrastructure secrets or monitoring credentials.

## Responsible reporting

If you believe you found a security issue affecting Zynost production systems, report it privately through the official Zynost contact channel rather than opening a public issue containing exploit details or credentials.

A useful report should include the affected component, reproduction steps, expected versus observed behavior, and impact. Do not access data that does not belong to you and do not disrupt live users or services.

## Public-source boundary

The public repository may describe trust boundaries, evidence methodology and security principles. Production code and secrets remain private unless a separately scoped component is intentionally released under an open-source license.
